# Battery Hub

Battery levels of your wireless mice, keyboards, headsets and speakers, in the Windows tray.

**Download:** open [the latest release](https://github.com/Axthrowa/battery-hub-releases/releases/latest) and pick one:

| File | For |
|---|---|
| `Battery.Hub_<version>_x64-setup.exe` | Most people. Installs Battery Hub, can start with Windows, updates itself. |
| `Battery.Hub_<version>_x64-portable.exe` | Runs from any folder without installing. Does not update itself. |

`latest.json` and `.sig` are for the built-in updater. You do not need to download them.

Windows SmartScreen may warn the first time (**More info → Run anyway**).

This repository only holds releases. The source code is private.

---

**İndir:** [en son sürümü](https://github.com/Axthrowa/battery-hub-releases/releases/latest) aç.
- Kurmak ve otomatik güncelleme için `…-setup.exe` dosyasını indir.
- Kurmadan çalıştırmak için `…-portable.exe` dosyasını indir.
